Xin chào, mình là Nguyễn Hữu Phúc

Mình theo đuổi Backend Developer, tập trung vào Java Spring Boot với định hướng xây dựng hệ thống ổn định, dễ mở rộng và hiệu năng tốt. Mình hứng thú với các bài toán có độ khó cao, luôn chủ động thử nghiệm, đo lường và tối ưu để tạo ra giải pháp thực tế, dễ vận hành.

Giới thiệu

Tổng quan về bản thân và định hướng phát triển

Mình là sinh viên năm 3 ngành Công nghệ Thông tin tại Đại học Sài Gòn, đang theo đuổi lộ trình Backend Developer với Java Spring Boot. Mình ưu tiên tư duy nền tảng: thiết kế API rõ ràng, cấu trúc dữ liệu hợp lý và code dễ bảo trì.

Trong quá trình học và làm dự án, mình thường đảm nhận các phần như thiết kế cơ sở dữ liệu, xử lý nghiệp vụ backend, xác thực phân quyền và tối ưu truy vấn. Mục tiêu của mình là tạo ra những hệ thống ổn định, chạy mượt và mang lại trải nghiệm tốt cho người dùng.

Mục tiêu ngắn hạn Nâng vững Spring Security, Redis và viết test bài bản.
Mục tiêu dài hạn Trở thành Backend Engineer có thể thiết kế hệ thống end-to-end.
Giá trị cá nhân Kỷ luật, chủ động học nhanh và không ngại thử thách.

  • Team size: 1 người
  • Vai trò: Backend Developer
  • Công nghệ: Java, Spring Boot, Spring Security, JWT, OAuth2, Spring Data JPA, MySQL, Flyway, VNPay API, Cloudinary
  • Tôi đã làm:

    • Tối ưu hiệu năng, xử lý N+1 query bằng JOIN FETCH và tuning repository.

  • Team size: 4 người
  • Vai trò: AI/Backend Developer

Laptop Shop Management System

Hệ thống quản lý cửa hàng laptop, hỗ trợ quản lý sản phẩm, đơn hàng và khách hàng trên cùng một nền tảng.
